pgAdmin

The PostgreSQL web UI for engineers — inspect tables, write ad-hoc SQL, review query plans. Starts on click, stops when idle.

Tier

Cold. pgAdmin is ~500 MB when running and is used ad-hoc, so it doesn't need to stay hot. Click Open pgAdmin in the dashboard — OrcheStack spins it up, you do your work, close your session, and it stops after the idle timeout.

Role

Engineer-only tool for exploring the warehouse. Stakeholders use Metabase; engineers use pgAdmin when they need raw SQL or schema inspection.

Configuration

  • PGADMIN_DEFAULT_EMAIL — admin login email
  • PGADMIN_DEFAULT_PASSWORD — admin password

On first launch, add a server connection pointing at postgres:5432 with your warehouse credentials.

Who has access

By default, only users with roles that have can_start=true and can_use=true on pgAdmin. That's typically Admin and Engineer. Analysts can be granted access per-role from the dashboard's Users → Roles page.
